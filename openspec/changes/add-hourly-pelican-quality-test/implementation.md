# 降智测试画廊：实施与使用记录

2026-09-28，第一版已在本地完成，分支 `codex/pelican-gallery`。基于原作者 `v0.2.8` / `a3eb7ef302961cba716dc78b39b93b60c467db0e`，尚未提交、推送或部署；未配置真实 API Key，也未产生真实模型调用。

## 使用入口

### 文件存储与兼容预览（策略 v2）

作品保存在 `PELICAN_ARTIFACT_DIR` 指定的私有目录；默认 `${DATA_DIR:-data}/pelican`。当前 Docker 环境对应容器 `/app/data/pelican`，宿主机 `/home/sub2api/runtime/data/pelican`。每轮按运行 ID 分目录，原始响应文件为 `source-<sha256>.txt`，预览为 `preview-<sha256>.html`。不将目录直接暴露为静态站点；登录用户通过鉴权接口查看预览，管理员查看和下载原文。

迁移 `243_local_pelican_files.sql` 新增路径和诊断字段。启动时逐份原子写文件、读回校验后清空旧文本字段；数据库只保存相对路径、校验值和元数据。迁移可重入，失败时不清除原文并停止自动生成。备份须同时包含数据库和作品目录；回退旧版应用前须恢复迁移前的 Pelican 表备份。过期任务及其文件按配置保留期清理。

预览不再因单个未知属性拒绝整份作品：保留常见绘图属性、渐变、滤镜、动画、SVG `use`、`foreignObject` 内的安全 HTML，以及纯 CSS 绘图；未知装饰属性单独移除，未知无害包装标签展开保留子内容。脚本、事件处理和外部资源从预览副本移除；隔离 iframe 和禁止脚本/网络的 CSP 保持启用。管理员可查看具体处理明细。

策略 v2 取代下方第一版的“失败源码不保存”规则：完整生成结果即使无法预览也保存原文。“重新生成预览”调用 `POST /api/v1/admin/pelican/runs/:id/preview`，只读取本地文件，不调用模型、不产生新的模型用量。旧版未保存原文的被拦截记录无法追溯恢复，界面明确提示。磁盘不可写会在模型请求前终止，避免明知无法保存仍付费生成。验证使用固定样例和隔离数据库，不新增付费测试。

### 2026-09-28：手动执行与可调频率

管理员可在 `/admin/pelican` 选择一小时、半小时或十分钟一次，保存后从下一个对应时间边界开始执行。既有配置通过新增迁移 `242_local_pelican_interval.sql` 保持默认 60 分钟，已执行的 `241` 迁移不变。界面显示新的下次执行时间和实际频率。

“立即执行”使用已保存的 Key、题目及超时配置；无需开启自动生成。管理员接口 `POST /api/v1/admin/pelican/run` 返回 HTTP 202 和运行 ID，由既有 worker 生成和保存结果。运行中互斥返回 409，手动请求间隔至少 10 秒（429）。手动执行不会修改自动计划或轮换序号；未保存设置时按钮提示先保存。生成期间运行记录每 5 秒刷新。

高推理强度、大量输出可能超过默认 300 秒超时，网关也可能在任务停止等待之后才返回成功。“等待超时”会在记录中明确标识，可在配置中调高请求超时（上限 600 秒）后手动重试。验证使用 mock 输出和独立测试数据库，不自动发起真实模型请求。

部署包含本次改动的前后端后，侧边栏可进入：

- `/admin/pelican`：管理员配置指定 Key、作品分组标签、题目模式、预算、超时和保留天数，并查看后台运行记录。
- `/pelican`：登录用户查看作品、按题目或分组筛选、点击放大。

功能默认关闭。首次启用需要服务器已有持久化的 `TOTP_ENCRYPTION_KEY`（或对应 `totp.encryption_key` 配置）；沿用站点现有值，不轮换已有加密密钥。未配置时页面禁用 Key 输入与启用按钮，后端同样拒绝存储 Key 或启用生成。

填写当前 sub2api 实例签发的 API Key，勾选分组、选择频率并启用后保存。首轮从下一个对应时间边界开始，扫描误差通常在 15 秒内。多选 A、B、C 仍只生成一份，该作品同时显示三个标签；标签不改变 Key 的路由、分组权限或计费。Key 的实际分组必须允许 `gpt-6-astra`，避免配置模型或推理强度改写；IP 限制也需允许本服务的本地请求。

默认三题轮换：鹈鹕滑雪、孙悟空开飞机、北极熊骑奥特曼，也可固定一个题目。模型固定 `gpt-6-astra`，推理强度固定 `high`。输出上限默认 16,384 token，超时 300 秒，历史保留 30 天；上限不是每轮固定消耗。公共提示词为：

> 只生成代码，不检查、不测试、不解释。仅输出完整HTML，用内联SVG和CSS，不用脚本或外链。

保存配置、刷新、翻页和放大只读取或写入配置/历史，不调用模型；管理员点击“立即执行”才会发起额外生成。清除 Key 同时关闭调度；关闭调度不追补缺失时隙，已开始的请求可在原超时内结束。

## 执行和展示规则

服务端定时扫描与单个异步 worker 分离，不依赖页面保持打开。数据库行锁、周期时隙唯一约束和运行中部分唯一索引共同防止多实例重复领取；租约与领取令牌防止过期 worker 覆盖终态。重启只考虑当前到期轮次，跳过更早时隙。模块每轮最多向本实例 `/v1/responses` 发出一次 HTTP 请求，无自动重试、补发或第二次模型修复；网关自身仍遵循站点已有路由和故障转移策略。

只有成功且符合预览策略的作品进入画廊。失败仅在管理员运行记录中显示固定诊断码，画廊不出现失败卡片或错误页面；列表刷新暂时失败时保留已有作品。没有浏览器验收、评分、自动检查代码效果、截图或裁判模型。

预览保留 HTML、内联 SVG、CSS 和受限 SVG 动画。后端解析与前端 DOMPurify 只做本地展示隔离，不调用模型、不执行生成代码。iframe 使用空 sandbox、独立来源和固定 CSP，禁用脚本、外链、网络请求及跳转。作品通过登录鉴权接口返回；原始源码只向管理员返回 JSON 字符串。

成功作品原文与预览各最多 1 MiB。失败源码不落库，只保存可用的用量和固定诊断码；上游错误正文不写入日志。指定 Key 加密保存，不回传明文或密文，配置保存请求的审计省略正文；管理员读取源码另记审计。历史标签按生成时快照保存。每小时分批清理最多 500 条过期终态，执行中任务不被清理。

### 复现检查

后端在 `backend/` 下运行：

```powershell
go test ./internal/pelican -count=1
go test ./internal/server/middleware -run Audit -count=1
go build ./cmd/server
```

设置 `PELICAN_TEST_DATABASE_URL` 指向专用测试 PostgreSQL 后，第一条命令会同时运行数据库和 HTTP 集成测试；不设置则显式跳过这些集成测试。测试账号需要创建与删除 schema 的权限，不要指向生产数据库。

前端使用当前锁文件兼容的 pnpm 10 安装依赖，在 `frontend/` 下运行：

```powershell

.\node_modules\.bin\vitest.cmd run src/features/pelican/__tests__ src/components/layout/__tests__/AppSidebar.spec.ts src/i18n/__tests__/localeKeyCompleteness.spec.ts src/i18n/__tests__/localesMessageCompile.spec.ts
```
